Server & Docker

CLI-Installation für verteilte Systeme

Installieren Sie ToolBoxV2 via Einzeiler-Skript oder Docker. Konfiguration über YAML für automatisierte Deployments.

# Linux / macOS
curl -fsSL https://get.simplecore.app | bash
# Windows PowerShell
iwr -useb https://get.simplecore.app/ps | iex
# Docker
docker pull ghcr.io/markinhaus/toolboxv2:latest
docker run -d -v ./data:/data ghcr.io/markinhaus/toolboxv2

Source & pip

Vollständige Kontrolle — aus dem Quellcode

Installieren Sie ToolBoxV2 als Python-Paket oder klonen Sie das Repository.

# pip install (empfohlen)
pip install toolboxv2[all]
# uv (schneller)
uv tool install toolboxv2[all]
# Development aus Git
git clone https://github.com/MarkinHaus/ToolBoxV2.git
cd ToolBoxV2
pip install -e ".[all]"
